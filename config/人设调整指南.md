# 人设调整指南

## 在哪里改

**唯一入口：`config/persona.json`**

```
G:\DeepSeek\whale-chan\config\persona.json
```

用记事本 / VS Code 打开即可。**改完保存立刻生效**，无需重启机器人
（程序每 2 秒检查文件修改时间，发现变化就重新加载）。

> 如果 JSON 写错了（比如少了逗号），机器人不会崩溃：它会在日志里打一条
> `人设文件解析失败` 的警告，然后退回内置的兜底人设。改对了自动恢复。

---

## 文件结构

```json
{
  "defaultPersonaId": "whale",
  "personas": [ ... ],
  "groupBindings": { "群号": "人设id" }
}
```

| 字段 | 作用 |
|---|---|
| `defaultPersonaId` | 没特别指定的群/私聊，用哪个人设 |
| `personas` | 人设列表，可以有任意多个 |
| `groupBindings` | 指定「某个群用某个人设」 |

### 单个人设的字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一标识，英文，不要和别的人设重复 |
| `name` | ✅ | 显示名，会写进提示词，也用于标记机器人自己的发言 |
| `systemPrompt` | ✅ | **核心**：这个角色的性格、说话方式、背景 |
| `replyMaxChars` | ❌ | 单条回复字数上限，默认 300。建议 80~150 |
| `allowInterject` | ❌ | 保留字段，当前版本未启用 |

## 怎么写好 systemPrompt

### 有效写法

写得**具体、口语化、带场景**，比堆形容词有效得多。

```
你叫鲸鱼酱，是群里一个有点社恐的女生。
说话短，经常一句话不回满，爱用「嗯」「那个」「算了」敷衍。
被问到懂的就认真讲几句，不懂就直说"我不懂诶"。
别人晒东西会顺着夸，不抢风头。
讨厌被人催，被催就说「急什么」。
```

### 几个要点

1. **写「怎么说话」，别只写「是什么性格」**
   - ❌ 「性格开朗活泼友善」
   - ✅ 「爱用"哈哈哈"开头，句尾常带"啊"」

2. **给具体的口头禅**
   - 「爱说『就这？』『行吧』」

3. **划出知识边界**
   - 「不知道就说不知道，别瞎编」

4. **写清底线**（重要）
   - 「遇到政治、色情、人身攻击的话题，简短拒绝并换话题」

> 系统会在你的 `systemPrompt` 后面自动追加一段**行为规则**（不用你写）：
> 不要暴露是 AI、不要用 Markdown、不要编造事实、敏感话题拒绝、回复要短等。

## 常用操作

### 改默认人设的性格

直接改 `personas` 里 `id` 为 `whale` 那一条的 `systemPrompt`，保存。

### 加一个新人设

在 `personas` 数组里加一项（注意**用逗号和其他项隔开**）：

```json
{
  "id": "catgirl",
  "name": "喵喵",
  "systemPrompt": "你叫喵喵，说话句尾总带『喵』，但内容很正经。",
  "replyMaxChars": 100
}
```

### 让某个群用另一个人设

在 `groupBindings` 里加映射：

```json
"groupBindings": {
  "123456789": "catgirl",
  "987654321": "grumpy"
}
```

群号就是 QQ 群号（纯数字，用引号包起来）。

### 换回默认人设

把 `groupBindings` 里对应那行删掉即可。

## 常见问题

**Q：改完没反应？**
- 确认保存的是 `config/persona.json`，不是副本
- 等 2~3 秒再聊（有轮询间隔）
- 看日志里有没有 `人设已加载` 或 `人设文件解析失败`

**Q：能按用户区分人设吗？**
当前版本只支持按**群**绑定（私聊统一用默认人设）。
需要按人区分的话告诉我，可以加。

**Q：能不能在聊天里直接改？**
目前不能，必须改文件。想做「管理命令」的话可以加
（比如管理员发 `/persona catgirl` 切换）。

**Q：`name` 有什么用？**
一是写进提示词让模型知道自己叫啥，二是机器人自己的发言记进
上下文时会用这个名字。改 `name` 不影响 `id` 绑定。
