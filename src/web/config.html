本地生图

用本机 ComfyUI 出图，不联网、不花钱。直接写中文，会自动翻成英文 tag。 512×512 约 10 秒，832×832（SDXL）约 25 秒。

两种输入方式，填原始提示词时自动模式失效。

自动模式（中文需求）

中文会走 LLM 翻译成英文 tag，并自动补画风、构图、光影词。

填的内容会追加到默认负向词后面，不是替换。

原始模式（英文 tag 直通）

填了这栏，上面的自动模式会被忽略。 不做翻译、不加画风词、不过滤——但也不会帮你补质量词和构图词， 写不全就容易出图糊。

填了则完全替换默认负向词。

实测：832 / 1024 / 1152 / 1216 都正常；1280 会爆显存降级到 274 秒，1536 直接失败。 超过 1024 后画面会变"扁平"（模型是硬拉，不是加细节），所以想要大图请用下面的放大。

先按上面的尺寸出图，再用放大模型放大 4 倍。实测只多 1 秒，显存几乎不变。
例：1024 出图 → 放大到 4096（16 MB）。这是真正增加细节，比直接画大图好得多。

仅在选择放大模型时生效。

勾选后不再拦截露骨描述，只影响这个面板——群里和 DSH 保持原有限制。
注意：中文需求仍需经过 LLM 翻译，模型自身的安全策略拦不住。 涉及未成年设定角色的色情内容会被拒绝，且属于违法行为。
绕过办法：直接把英文 tag 写进输入框（如 1girl, tohsaka rin, white thighhighs）， 英文不经过 LLM，只受本机策略约束。
